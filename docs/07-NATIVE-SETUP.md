# 07 · Native Setup (Bare React Native)

This project ships the **JavaScript/TypeScript source and config only**. The `android/`
and `ios/` folders are generated by the React Native CLI — then patched with the steps
below. Doing it this way means you get the native project matching your exact RN and
toolchain versions rather than a stale copy.

---

## Step 1 · Generate the native projects

```bash
npx @react-native-community/cli@latest init PreMarketIQ --version 0.74.5
```

Then copy this repo's files over the generated project:

```
src/                 → replaces the generated App.tsx
index.js
app.json
babel.config.js
metro.config.js
react-native.config.js
tsconfig.json
package.json         ← merge dependencies, keep the generated scripts if you prefer
.env.development
.env.production
assets/fonts/
docs/
```

Keep the generated `android/` and `ios/` folders. Then:

```bash
npm install
cd ios && pod install && cd ..
```

---

## Step 2 · react-native-config (env vars)

**Android** — `android/app/build.gradle`, near the top:
```gradle
apply from: project(':react-native-config').projectDir.getPath() + "/dotenv.gradle"
```

Select the env file at build time:
```bash
ENVFILE=.env.development npm run android
ENVFILE=.env.production  npm run android
```

**iOS** — in Xcode, add a Build Phase → New Run Script Phase, placed **before**
"Bundle React Native code and images":
```sh
cp "${PROJECT_DIR}/../.env.development" "${PROJECT_DIR}/../.env"
```
Point release configurations at `.env.production`.

> **Remember:** these values are baked in at build time. Editing `.env` and reloading
> Metro changes nothing — you must rebuild.

---

## Step 3 · Cleartext HTTP for local development

Your Spring Boot service runs on `http://` locally, and both platforms block that by default.

**Android** — create `android/app/src/main/res/xml/network_security_config.xml`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<network-security-config>
  <domain-config cleartextTrafficPermitted="true">
    <domain includeSubdomains="true">10.0.2.2</domain>
    <domain includeSubdomains="true">localhost</domain>
    <!-- add your LAN IP for physical-device testing -->
    <domain includeSubdomains="true">192.168.1.7</domain>
  </domain-config>
</network-security-config>
```
Reference it in `android/app/src/main/AndroidManifest.xml`:
```xml
<application
    android:networkSecurityConfig="@xml/network_security_config"
    ... >
```

**iOS** — `ios/PreMarketIQ/Info.plist` (debug only):
```xml
<key>NSAppTransportSecurity</key>
<dict>
  <key>NSAllowsLocalNetworking</key>
  <true/>
</dict>
```

⚠️ Both are **development-only**. Production uses HTTPS/WSS — never ship a blanket
`NSAllowsArbitraryLoads` or app-wide cleartext.

## Step 4 · Permissions

**Android** — `AndroidManifest.xml`:
```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />  <!-- Android 13+ -->
<uses-permission android:name="android.permission.VIBRATE" />
```

**iOS** — push capability is added in Step 6. No extra Info.plist keys are needed for
networking beyond Step 3.

## Step 6 · Firebase Cloud Messaging

**6.1 Console**
1. Create a Firebase project.
2. Add an **Android** app with package `com.premarketiq` → download `google-services.json`
   → place in `android/app/`.
3. Add an **iOS** app with your bundle id → download `GoogleService-Info.plist` → drag into
   the Xcode project (check "Copy items if needed", add to target).
4. Upload your **APNs authentication key (.p8)** under Cloud Messaging → Apple app config.
   Without this, iOS pushes silently never arrive.

**6.2 Android Gradle**

`android/build.gradle` (project level), in `buildscript.dependencies`:
```gradle
classpath 'com.google.gms:google-services:4.4.2'
```

`android/app/build.gradle`, at the bottom:
```gradle
apply plugin: 'com.google.gms.google-services'
```

**6.3 iOS**

In Xcode → Signing & Capabilities, add:
- **Push Notifications**
- **Background Modes** → check *Remote notifications*

`ios/PreMarketIQ/AppDelegate.mm` — add the Firebase import and configure call:
```objc
#import <Firebase.h>

- (BOOL)application:(UIApplication *)application
    didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
  [FIRApp configure];          // must run before React Native starts
  // ...existing code
}
```

Then:
```bash
cd ios && pod install && cd ..
```

**6.4 Verify**
Send a test message from Firebase Console → Cloud Messaging → "Send test message", pasting
the FCM token your app logged. Check all three states: foreground, background, killed.

## Step 7 · Fonts (optional)

Drop the four IBM Plex `.ttf` files into `assets/fonts/` (names listed in the README there),
then:
```bash
npx react-native-asset
```
Rebuild afterwards. If you skip this, remove the `fontFamily` entries from `src/theme.ts`
and the app uses system fonts — it runs fine either way.

## Step 8 · Release builds

**Android**
```bash
cd android
./gradlew assembleRelease     # APK
./gradlew bundleRelease       # AAB for Play Store
```
Generate a keystore and configure signing in `android/app/build.gradle` +
`android/gradle.properties`. Never commit the keystore or its passwords.

**iOS**
Archive from Xcode (Product → Archive) with a Release scheme pointing at
`.env.production`.

**Before every release:**
- [ ] `USE_MOCK=false`
- [ ] URLs are `https://` / `wss://`
- [ ] `npm run typecheck` clean
- [ ] Cleartext exceptions removed from the release config
- [ ] Version + build number bumped

## Troubleshooting

| Error | Fix |
|---|---|
| `Config.API_BASE_URL` is undefined | `dotenv.gradle` not applied, or the iOS run-script phase is missing/after the bundle phase |
| `Network request failed` (Android, http) | Cleartext config — Step 3 |
| `TextEncoder is not defined` | `import './src/polyfills'` must be the first import in `index.js` |
| `RNKeychain could not be found` | `pod install` not run after adding the dependency |
| Duplicate class / Gradle merge errors | `cd android && ./gradlew clean` |
| Metro serving stale code | `npm start -- --reset-cache` |
| iOS push never arrives | APNs `.p8` not uploaded to Firebase, or Push capability missing |
| Fonts not applied | `npx react-native-asset` not run, or app not rebuilt |
